SB TECH PORTFOLIO
=================

Files:
- index.html
- style.css
- script.js
- assets/sb-logo.png
- assets/ceo.png

HOW TO USE
1. Upload the complete SB_Tech_Portfolio folder to your hosting.
2. Make sure index.html is in the website root/public_html.
3. Open index.html in a browser.
4. In index.html, replace:
   - your-email@example.com
   - 2340000000000
   with SB Tech's real email and WhatsApp number.

The website is responsive and uses the supplied SB Tech logo and CEO photo.
